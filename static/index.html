Scalability Strategy: Supporting 100,000 Users

  • Concurrent Voice Capacity: At 100k MAU (~3–5% peak concurrency = 3,000–5,000 simultaneous calls), deploy stateless ASGI WebSocket workers on Kubernetes (HPA on active WS connections + CPU) behind Envoy/ALB sticky-session routing.
  • Multi-Region Edge PoPs: Geo-route voice media to US-East, EU-Central, and AP-South (Mumbai) to keep RTT < 60ms and meet GDPR / India DPDP data residency.
  • Distributed Memory & RAG: Move SQLite to PostgreSQL + pgvector / Qdrant with read replicas, and store hot session turn context in Redis Cluster (<2ms read).
  • Async Event Bus: Decouple CRM webhooks, call summarization, and analytics into Kafka / RabbitMQ worker queues so voice turns never block on third-party CRM rate limits.
  • LLM Cost & Latency Tiering: Route 80% of qualification/FAQ turns to fast distilled/flash models + semantic cache, reserving frontier models for complex enterprise objections.
